# .github

Org-wide defaults for [branchLeft](https://github.com/branchLeft) repositories.

Files here (`CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md`, issue/PR templates) are used automatically by any branchLeft repo that doesn't define its own copy. See [docs/GITHUB-SETUP.md](docs/GITHUB-SETUP.md) for what's configured across the org and why, and `scripts/` for the tooling that applies it.

[docs/DOCUMENTATION-STANDARD.md](docs/DOCUMENTATION-STANDARD.md) is how documentation and code comments are written across the org.
