# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting: go to the **Security** tab of the affected repository → **Report a vulnerability**. This opens a private advisory visible only to maintainers.

If you're unable to use that, email contact@branchleft.co.uk with details.

## Supported versions

These are small, actively-developed projects. Only the latest release of `@branchleft/components` and the current `main` of `website` are supported — there is no long-term-support branch.

## What to expect

We aim to acknowledge reports within a few days. There is no bug bounty program.
